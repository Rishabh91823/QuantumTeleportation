#Quantum Teleportation Protocol#

1st Year Engineering Physics Project - VIT Chennai

This repository contains a Python-based simulation of a Quantum Teleportation Protocol using IBM's Qiskit SDK. The project demonstrates how to transmit quantum information (a qubit's exact state) from one location to another using quantum entanglement and classical communication.

🚀 Project Overview

Quantum teleportation does not transport physical matter; rather, it transports the quantum state of a particle. In this simulation, we prepare a specific quantum state on Alice's qubit (Qubit 0) and teleport it to Bob's distant qubit (Qubit 2) using a shared entangled pair.

Prerequisites

To run this simulation locally, you need Python installed along with the Qiskit and Matplotlib libraries.

pip install qiskit qiskit-aer matplotlib
